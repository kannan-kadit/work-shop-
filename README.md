## 🌟 Key Features

1. **Workshop Management Dashboard**
   - Live intake statistics, revenue tracking, low-spares alert buffer.
   - Kanban workflow (*Received ➔ Inspection ➔ In Progress ➔ Quality Check ➔ Ready for Pickup ➔ Delivered*).
   - Fast filter by status, bike brands (*Royal Enfield, Yamaha, Honda, TVS, KTM, Hero*), and search by registration number (`TN 74 ...`).

2. **Job Card Creation & Diagnostic Sheet**
   - Vehicle & customer intake with fuel gauge selector (`E`, `1/4`, `1/2`, `3/4`, `F`).
   - Interactive motorbike inspection diagram with clickable damage/scratch pinpoint markers.
   - Real-time spare parts linking with live inventory deduction, labor charges, and GST calculation.

3. **GST Tax Invoice & WhatsApp Bill Sharing**
   - Professional A4 GST Tax Invoice layout with HSN/SAC codes, CGST/SGST tax breakdown, and Terms & Conditions.
   - Dynamic UPI QR Code for instant GPay / PhonePe payment.
   - One-click **WhatsApp Bill Share** with pre-formatted invoice text and direct WhatsApp link.

4. **Spare Parts & Lubricants Inventory**
   - Live stock management for Motul 7100 15W50, Castrol Power1, Yamalube 4T, disc pads, brake shoes, spark plugs, and chains.
   - Low-stock warning indicators, category filters, and 1-click restock modal.

5. **Mechanic Workstation Bay Terminal**
   - Dedicated screens for Chief Mechanic Murugan, Selvam, Arumugam, and Vignesh.
   - Interactive repair checklists and live status log posters for customer tracking.

6. **Customer Live Tracker & Doorstep Booking Portal**
   - Real-time animated stage tracker (`TN 74 AX 4419`).
   - Doorstep service booking across Kottar, Chettikulam, Vadasery, and Nagercoil.
   - Digital Service Passport with official maintenance verification stamps.
   - 24/7 Roadside Assistance SOS Dispatcher for breakdown emergencies.

7. **Mobile App Simulator & PWA**
   - Smartphone mockup with bottom navigation (*Home, Tracker, Packages, Spares, SOS*) and Customer/Mechanic mode toggle.
   - Full-width responsive fluid layout with clean white background and dark typography.

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS + Vanilla CSS Variables
- **Icons:** Lucide React
- **Animations / Effects:** Canvas Confetti

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KANNANGIT2024/work-shop-.git
   cd work-shop-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
